# 02. UX, экраны, копирайтинг
Принципы: крупные шрифты (аудитория 45+, поддержка scaled font до 200%), один главный глагол на экран, никаких медицинских обещаний, цвет-статусы дублируются иконками и текстом (доступность).

## 1. Экраны и навигация
Нижняя навигация (4 вкладки) + модалки:
1. **Сегодня** (главная) — чип подопечного сверху; карточки приёмов на сегодня («Принято / Не принято / Отложить»); баннеры: остаток лекарства, завтра визит; FAB «+».
2. **Лекарства** — список активных (группировка по времени), архив, лимит-счётчик (Free «4 из 5»).
3. **Дневник** — лента записей и визитов (сегменты), поиск; FAB записи.
4. **Профиль** — подопечный (аллергии, врачи), экстренная карточка, документы, чек-листы, отчёты/PDF, «Моя подписка», приватность, настройки (тема, крупный шрифт, тихие часы, OEM-помощь), демо-данные, поддержка.
Модалки: онбординг (4 шага), форма лекарства, paywall, пакет передачи, экспорт/backup.

## 2. User flow первого запуска
Запуск → Welcome (ценность, 1 экран) → «Кому вы помогаете?» (имя+год) → «Добавим первое лекарство» (название, доза, 1–3 времени) → **системный запрос уведомлений** (предварительный экран-объяснение → диалог) → точные будильники (если требуется) → OEM-обучение (если Xiaomi/Huawei/Honor детект) → «Готово, первое напоминание — {дата/время}» → Сегодня. Onboarding засчитан. Paywall на D2+ по триггеру.

## 3. Flow «добавить лекарство»
FAB/+ → форма: название (поиск по прошлым) → форма/доза → расписание (дни, времена чипами) → опции: остаток (P), заметка → «Сохранить» → тост «Напомню в 09:00» + превью-карточка. Лимит Free → paywall-sheet (триггер med_limit).

## 4. Flow «включить напоминания»
Pre-permission экран: «Напоминания нужны, чтобы близкий не пропустил таблетку. Мы не рассылаем рекламу.» → системный диалог POST_NOTIFICATIONS → разрешено → проверка canScheduleExactAlarms → отказ → экран «Как включить» (инструкции OEM) + fallback «напоминать примерно вовремя».

## 5. Flow «экспорт PDF»
Профиль → «Отчёты для врача» → выбор периода → [Free] базовая карта / [P-триггер] «Расширенный отчёт с динамикой» → генерация → системный шаринг. pdf_export_started/completed.

## 6. Flow «вход в Premium»
Триггер → bottom sheet (что разблокируется) → полный paywall: заголовок, 3 тарифа (год выделен «−66%»), «3 дня бесплатно», ниже — цена после триала и ссылки оферты → шторка RuStore Pay SDK → успех: конфетти-без-детства, экран «Premium включён, что дальше» (3 подсказки).

## 7. Flow «пригласить помощника» (v1)
Профиль → «Помогать будет ещё кто-то?» → объяснение: «В v1 — пакетом для передачи, живая синхронизация появится позже» → создать «Пакет передачи ухода» (P-триггер) → выбрать получателя в мессенджере → чек-лист «что передать». family_invite_created (параметр — только канал).

## 8. Пустые состояния
- Сегодня: «Сегодня приёмов нет. Добавьте лекарство — и я напомню вовремя.» + кнопка.
- Дневник: «Первая запись — опора для врача. Запишите, что беспокоит сегодня.»
- Визиты: «Запишите ближайший приём — напомню за день.»
- Documents/чек-листы — аналогично, глагол+выгода.

## 9. Состояния ошибок (тексты)
- Нет сети при покупке: «Платёж не прошёл. Деньги не списаны — попробуйте ещё раз, когда будет интернет.»
- Подписка не подтверждена: «Не удалось проверить подписку. Бесплатные функции работают как обычно.»
- Ошибка экспорта: «Файл не создался. Попробуйте ещё раз или сделайте резервную копию в настройках.»
- Пропущено: в уведомлении — «Не принято» → в приложении мягкая карточка «Отметить причину» (без давления и красного).

## 10. Тексты запросов разрешений
- Уведомления (pre): «Напоминания о таблетках и визитах. Только ваши напоминания — никакой рекламы.»
- Точные будильники (OEM-экран): «Чтобы напоминание пришло ровно в 9:00, а не „когда телефон соизволит“.»
- Камера: «Фото анализов и записей врача. Остается в этом телефоне.»
- Уведомления (отказ): «Без уведомлений напоминаний не будет. Включите в настройках телефона → Уведомления.»

## 17. Инструкции OEM (тексты экранов; скриншоты настроек — в бете)
**Xiaomi/Redmi/Poco (MIUI/HyperOS):** Настройки → Приложения → Круг заботы → «Контроль активности» — Разрешить; Автозапуск — Включить;Battery → не оптимизировать. Убрать приложение из недавних не свайпом «на سرعة», а удержанием «Закрыть все» — иначе будильники снимаются.
**Huawei/Honor (EMUI/Magic):** Настройки → Приложения → Запуск приложений — вручную для «Круг заботы» (Автозапуск/Косвенный запуск/Фоновый активный запуск — вкл); Батарея → запуск → без ограничений; отключить «Удаление фоновых процессов» в недавних.
**Samsung One UI:** Настройки → Батарея → «Не оптимизировать» для приложения; отключить энергосбережение режима «Макс.»
**Общий текст при отказе точных будильников:** «Android ограничивает точные напоминания в вашем телефоне. Напоминания будут приходить с задержкой до 15 минут. Включить точность: Настройки → Приложения → Круг заботы → Напоминания и будильники → Разрешить.»

## 18. Доступность
Поддержка крупных шрифтов (тест 200%), контраст ≥4.5, touch target ≥48dp, статусы дублируются текстом, TalkBack-лейблы карточек приёма («Эналаприл 5 мг, 9 утра, не принято»).

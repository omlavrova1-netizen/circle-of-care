- TC-22 «Не принимал» + чип причины → skipped, повторы сняты.

- TC-24 (P0) Reboot до срабатывания → после загрузки будильники восстановлены (проверка на реальном Xiaomi + Huawei).

- TC-28 Телефон выключен на момент срабатывания → после включения «пропущено» + возможность «принято вне приложения».

## Чек-лист беты (20–30 семей, 10–14 дней)
[ ] 3+ устройства разных вендоров у бета-тестеров (обязательно 1 Xiaomi/Redmi, 1 Samsung, 1 Huawei/Honor)
[ ] Сценарий «неделя ухода»: 3 лекарства, 2 визита, 5 записей дневника, 1 PDF врачу, 1 пакет передачи
[ ] Пульс: D1/D3/D7 retention беты; % подтверждённых приёвов в срок ≥85%
[ ] Формы фидбека: TG-опрос (5 вопросов) + 3 интервью с «организаторами»
[ ] Метрика доверия: «покажу приложение знакомым» (NPS-lite) ≥7/10
[ ] Сбор 30+ отзывов в RuStore после релиза: план через soft-prompt (docs/11)
